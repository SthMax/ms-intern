# Knowledge Base

This folder is the source of truth for research findings. Slides are a summary of
this material, never an independent source.

## Evidence states

- **Candidate:** discovered but not checked against the original source.
- **Verified-primary:** manually checked against an official regulator, company,
  exchange, filing, or vendor source.
- **Corroborated:** verified-primary evidence plus an independent supporting
  source where useful.
- **Unresolved:** relevant but ambiguous, inaccessible, superseded, or conflicting.

Only `verified-primary` and `corroborated` claims should appear as facts in the
main presentation. Candidate and unresolved items may appear only as clearly
labelled gaps or questions.

## Required citation fields

Each source in [source-register.md](source-register.md) needs:

- Stable source ID.
- Exact title and issuing organization.
- Publication date and, for rules, effective/status dates.
- Direct URL (prefer an official primary source).
- Access date.
- Relevant article, section, page, or timestamp.
- Short paraphrase of what the source supports.
- Scope and caveat.
- Evidence state.

## Workflow

1. Add a candidate to the source register; do not write the desired conclusion
   first.
2. Open the primary source and verify identity, date, status, and relevant text.
3. Create an evidence note using
   [templates/evidence-note.md](templates/evidence-note.md).
4. Link the note from the appropriate index.
5. Express interpretations separately from source content.
6. Before slide freeze, test every material claim by following its links manually.

## Citation discipline

- Prefer Chinese-language originals where authoritative; translations are aids,
  not replacements.
- Do not cite search snippets as evidence.
- Do not infer “no adoption” from an absence of public disclosure.
- Record asset-size metric, scope, date, and source; do not mix total AUM, public
  mutual-fund AUM, non-money-market AUM, and group-wide AUM.
- Preserve uncertainty. “Announced,” “piloted,” “deployed,” and “production use”
  are different claims.
- Keep short quotations only when exact wording matters; otherwise paraphrase and
  point to the exact section.
- Check whether a rule is current, amended, repealed, draft, consultation, or
  formally effective.

## Data handling

This knowledge base is designed for public information. Do not place internal,
confidential, client, personal, portfolio, position, or licensed research data
here unless an authorized owner has explicitly approved both the use and storage
location. Record internal-policy questions without reproducing restricted policy
text.
