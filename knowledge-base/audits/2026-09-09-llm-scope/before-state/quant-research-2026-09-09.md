# 量化重点研究方向 — 2026-09-09

这轮将范围扩展到**纯量化机器学习＋LLM辅助量化研发**。最值得优先深入的是：易方达的标签期限优化、LLM自动因子研发，以及新闻事件驱动的行业/ETF轮动。组合优化与交易约束也重要，但目前公司公开材料的实现细节相对不足。

资料评分沿用此前用户口径；公开了代码仍需核清该代码对应的工作流和结果，不因项目知名或论文收益漂亮就给5分。本轮未运行模型/回测、未调用付费API、未取得或上传机构数据；本文评价的是研究材料，不评价投资可行性或基金业绩。

公司调研的量化侧重点建议放在**易方达、富国、华泰柏瑞、中欧**。易方达拥有本轮最强的署名论文与代码证据；富国的公司案例对文本因子最具体；华泰柏瑞适合研究投研体系和风控分工；中欧适合追组合优化实现。原有公司整体评分暂不改，易方达仍为4分，另列量化代码候选。

## 2. 易方达：Label Horizon Paradox

一手出处：[arXiv v5，2026-08-19](https://arxiv.org/abs/2602.03395v5)；[官方代码固定版本81c8098](https://github.com/EFundAI/label-horizon-paradox/tree/81c8098acdab2b0008a10f88c7e47321207ad509)。论文第1页列Chen-Hui Song、Shuoling Liu、Liyuan Chen三位作者的易方达单位署名，并列ICML 2026/PMLR 306；ICML官方[下载目录](https://icml.cc/Downloads/2026)亦包含该题名。

**研究价值：直接研究训练目标，而非只换模型架构。** 同一目标收益可能同时包含逐步兑现的信号和随时间积累的噪声，论文研究二者平衡。它不是“3天标签永远最好”的规则；最佳期限应随市场、样本、模型和预测目标变化。

官方demo的具体流程：

| 环节 | 已披露内容 | 对应实现 |
|---|---|---|
| 输入 | 日频行情、VWAP、可交易掩码、历史指数成分、Alpha158因子；明确parquet schema | `docs/data.md`、`src/data_utils.py` |
| 标签 | 候选h=1…10；目标固定10天；信号在t日形成，标签为 `VWAP[t+h+1]/VWAP[t+1]-1` | `scripts/run_blo.py:build_tensors` |
| 基线 | 逐h训练MLP `158→256→128→1`，多随机种子，验证集选epoch，输出alpha文件 | `scripts/run_search.py` |
| 标签优化 | softmax权重λ；内层更新学生模型，外层用目标期限IC更新λ；有预热、时间间隔、熵正则和多种子聚合 | `src/blo_trainer.py`、`scripts/run_blo.py`、`docs/blo.md` |
| 检验 | λ与逐h基线IC排名比较；代码中的`R_AGG`是报告评价参照，不直接当作BLO梯度目标 | `scripts/run_blo.py` |
| 回测 | 基线alpha→10组错位调仓子组合；指数成分筛选、等权Top-N、VWAP成交、佣金/印花税、净值和换手 | `scripts/run_backtest.py`、`engine/`、`docs/backtest.md` |

**必须分开两套实验。** 论文v5主要使用分钟数据构造特征，并讨论多市场/模型实验；公开仓库自称独立日频demo，采用公开定义的Alpha158。原论文特征未完整公开，不能把demo收益当成论文表格的直接复现。仓库的行情也未再分发，DolphinDB内部连接不可用，需要按已给schema准备合法来源的数据；MIT是代码许可，不是行情授权。

静态核查发现三个影响复现的点：

1. **BLO与回测未形成所见代码中的同一输出链。** `run_blo.py`输出λ和排名相关性CSV；`run_backtest.py`读取`results/alphas/h{h}`的逐期限基线预测。仓库收益表可以支持“不同固定训练期限的比较”，不能直接支持“BLO自动选期限后组合收益”。要验证后者，需明确λ如何生成最终模型/信号，并单独回测。
2. **边界标签需要清除跨段样本。** `build_tensors`先用全量价格构造前瞻标签，再按信号日期选择train/valid；目标价格在t+h+1，边界附近可能落入后一数据段。代码中的内外层间隔不能自动代替训练/验证/测试边界的清除与隔离。
3. **回测简化已明示。** 没有滑点/市场冲击、成交量参与约束、完整行业/风格风险模型和容量控制；买卖共用全日VWAP。仓库中的高收益/Sharpe只是其简化实验报告，本轮没有独立重跑。文档用`Ann/Sharpe`展示波动率的口径也需要回到净值序列独立计算，不能默认复合收益年化等同均值年化。

因此，这个方向非常值得做，但完整材料和可信绩效是两个问题。本轮保留为5分候选，先不把易方达整体升到5。

## 3. LLM自动因子研发：最适合和原项目衔接

易方达与南洋理工、新加坡国立大学作者合著的[Alpha mining综述](https://doi.org/10.1631/FITEE.2500386)，发表于FITEE 26(10):1809–1821，已入库FUND-122。它将流程拆成**提出因子、实现、回测、评价**四个环节，讨论LLM在不同位置的作用及评估/泄漏/多样性局限。综述是技术路线图，不能据此认定文中所有框架均由易方达部署。

可深入研究的外部实现是[微软RD-Agent](https://github.com/microsoft/RD-Agent/tree/32b3d395e73d9db5eee3fe9063d69aec0fdc83bd)。[论文v2](https://arxiv.org/abs/2505.15155v2)有42页方法、实验、Prompt、消融和局限；代码包含因子/模型两条开发分支、调度器、代码生成、Qlib运行和反馈。作者单位为微软研究院及合作高校，单独放在[外部方法参考](../reference/quant-methods/README.md)，不增加基金公司数量。

可以检查到的闭环是：经济假设→因子或模型任务→生成实现→训练与回测→读取IC/收益/回撤→决定保留/修改→调度下一轮。富国[FUND-007物理PDF第8页](../sources/FUND-007/original.md)则提供国内应用对照：公司披露从舆情提取政策敏感度因子、Transformer情绪因子，以及让LLM参考因子绩效做评价；公式、Prompt和对应代码尚未完整公开，因此仍为3分。

RD-Agent的复核要点已经有代码依据：

- `factor_template/conf_combined_factors.yaml`把回测期设为`test_start/test_end`；`developer/feedback.py`把所得IC、成本后年化收益和最大回撤传入下一轮。**这段“test”实际参与自适应搜索，不能同时作为独立最终测试。** 这是当前固定版本默认流程的观察，不是对论文全部实验或作者运行配置的推断。
- 论文第24页既出现开盘调仓/全部卖出的文字，也出现收盘价成交/保留高排名持仓的文字；同页成本叙述亦有0.5%与0.05%买入、0.15%卖出的不一致。当前配置是`TopkDropoutStrategy(topk=50,n_drop=5)`、`deal_price=close`、`open_cost=0.0005`、`close_cost=0.0015`。复现时需以明确固定的策略与成本口径重算，不能混用。
- 论文的API支出与硬件/运行时长分开记录：第19页实验服务器为4张A6000，不能把宣传的少量API费用当作总研究成本，也不能由此推断所有简化实验都需要4卡。当前仓库比论文晚，不能假定这个commit就是论文实验版本。

若接到原项目的单GPU/本地模型评估，建议先**固定LightGBM，仅研究因子生成**，与固定因子库、人工经济假设和同预算随机/公式搜索比较。先限制允许的输入字段、时间算子与搜索次数，再比较新增因子的IC、相关性、成本后组合表现、失败率和人时节省。模型联合优化可作为扩展，避免初轮同时改变所有组件而无法归因。这是研究设计建议，本轮尚未执行。

## 4. 文本信号与ETF轮动

MENTOR本身已经是量化相关方向：把新闻事件转成未来事件及行业排名，公开教师反馈、策略更新Prompt与评价；它与“研报摘要助手”的任务不同。另一条独立路线是易方达联合高校的NLPCC投资Agent任务，提供新闻/价格输入、ETF池、标准化日频模拟和代码。

可形成的具体研究题目是：**“新闻文本在价格模型之外，是否对行业轮动提供增量信息？”** 建议至少比较价格信号、文本信号、两者融合，并加入原新闻与打乱时间/打乱证券映射的负对照。新闻披露时刻、事件去重、证券映射、价格复权和交易时点必须一致；解释写得合理不能替代增量预测检验。

NLPCC代码对当前日行情隐藏收盘价等字段，新闻允许当天15点前内容；数据使用受非商业学术条款限制，最终B榜不公开。它适合研究Agent评测结构，不宜被写成已取得基金公司实盘轮动策略。MENTOR与NLPCC不能拼接为同一已验证生产链。[上一轮逐项核查](focused-research-2026-09-09.md)

## 5. 组合构建与风险：公司跟进对象

| 公司 | 与量化相关的现有披露 | 继续找什么 |
|---|---|---|
| 富国 | 非线性/情绪/政策敏感度因子、轮动、因子评价、组合风险归因 | 因子公式或标注schema；中性化、去相关/增量筛选；策略成本与测试期 |
| 华泰柏瑞 | 公告/纪要/舆情转结构化研究数据；价格与文本融合；集中度、流动性、基准偏离硬规则 | 单一真实因子/事件流程、Prompt/样本、信号进入组合的方式及样本外评价；文章描绘的自主研究Agent部分是未来设想 |
| 中欧 | 与上交智算合作，优化器用于组合与多账户交易；披露求解提速 | 精确优化目标、风险模型、流动性/公平交易约束、求解质量与硬件基线；提速不等于alpha或收益提高 |

这三家当前公开材料可用于产业应用与需求对照；本轮未取得足够原始实现，将它们的量化工作流直接升到4/5仍依据不足。

## 6. 建议选择

**如果以你的量化兴趣优先：先做A1标签期限优化。** 问题具体、有基金公司署名和代码，能深入训练目标、泛化、时间切分和组合检验，也适合形成扎实的方法复核。

**如果同时要紧扣现有LLM实习研究主线：先做A2自动因子研发。** LLM在这里是提出/实现研究假设的工具，可比较不同模型、调用成本和生成代码质量，与原有技术选型及PoC衔接最直接。

**A3事件轮动适合作为第二案例。** 它连接非结构化文本和可检验量化信号，能和A2互补；应尽早确认语料和行情可用性。组合优化放在已有可信信号之后研究，避免仅因求解更快就判断投资更好。

本轮入库FUND-120–122及微软外部方法资料；原有来源原件和评分保留。版本、代码路径及验证记录见[本轮审计](../audits/2026-09-09-quant-research/README.md)。
