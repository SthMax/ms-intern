# 易方达指数直通车 AI Skills

> 基金行业内率先面向 AI 智能体打造的官方指数基金数据查询工具。以标准化技能形式开放，让 AI 助手即可获取专业的指数数据服务。

## 服务简介

指数直通车 AI Skills 是易方达基金专为 AI 智能体（如 OpenClaw、字节跳动 ArkClaw、腾讯 WorkBuddy 等）打造的指数产品数据查询工具。它致力于搭建大模型与指数基金市场之间的信息桥梁，助力各类智能体实时调取准确、齐全的指数、场内 ETF 与场外指数基金产品数据，全面覆盖指数基金检索、持仓分析、分红追踪等核心应用场景，显著提升指数投资的数据获取与分析效率。

## 技能清单

本技能包包含两大独立核心技能：

| 技能 | 说明 | 适用场景 |
|------|------|----------|
| `index-query` | 指数信息查询 | 指数基础信息、分类、编制属性、成分股、行业和市值分布、区间收益、波动与回撤、PE/PB/PS估值及历史分位、ROE、股息率、营收和利润增速、相关ETF或场外基金，以及最新点位、涨跌、成交和分钟走势 |
| `etf-fund-query` | ETF（交易型开放式指数基金）信息查询 | 场内ETF基础信息、规模费率、持仓明细、历史分红、区间收益、资金流向、涨幅榜、热搜榜、按股票反查ETF |
| `open-fund-query` | 场外指数基金信息查询 | 场外指数基金净值、规模、收益、基金经理、风险等级、持仓、联接基金关系、A/C份额比较 |

> 因有关要求，本 skill 不提供实时行情类信息。相关信息可以通过访问小程序和网站获取。

## 快速开始

### 方式一：一键安装（推荐）

1. 访问易方达指数直通车小程序
2. 点击 AI Skills 入口，免费领取 API Key
3. 一键复制有关指令发送给你的 AI 助手，联网条件下自动完成安装

### 方式二：手动安装

1. 下载本仓库到本地。
2. 将 `Index-Hub` 文件夹发送给你的 AI 助手，并提示其完成安装。
3. 当 AI 助手提示需要 API Key 时，按下方「获取 API Key」步骤获取并发送 Key 给 AI 助手即可。

### 获取 API Key

1. 扫码登录**易方达指数直通车小程序**
2. 在小程序首页点击 Banner 图或 AI Skills 入口
3. 点击「立即领取 API Key」
4. 进入我的 API Key 管理页面，复制您的 Key，发送给你的 AI 助手

⚠️ **安全提示**：请勿将 API Key 泄露至公共网络空间。如发现异常调用，请进入小程序 AI Skill 页面 → 我的 API Key 管理 → 申请重置。

## 数据能力

### 指数查询能力（`index-query`）

| 能力 | 说明 |
|------|------|
| 指数基础信息 | 查询某只指数的名称、分类、发布时间、基日、编制机构 |
| 指数筛选与比较 | 按分类、表现、估值、基本面或跟踪产品条件寻找和比较指数 |
| 成分股查询 | 查询指数前十大成分股，或按一只或多只股票反查相关指数 |
| 行业与市值分布 | 查询指数的行业权重、大中小盘数量和占比 |
| 收益与风险 | 查询区间收益、年化收益、波动率、最大回撤或夏普比率 |
| 估值与基本面 | 查询PE、PB、PS、历史分位、ROE、股息率、营收或利润增速 |
| 相关基金 | 查询跟踪指数的ETF、场外基金、数量和规模 |
| 实时行情 | 查询最新点位、涨跌额/幅、成交量/额或分钟走势 |

### ETF 查询能力（`etf-fund-query`）

| 能力 | 说明 |
|------|------|
| 关键词搜索ETF | 按代码、名称、指数、主题召回ETF候选 |
| 批量ETF详情 | 查询规模、费率、跟踪指数、基金经理、年化跟踪误差、资金流向等 |
| 批量ETF持仓 | 查询前十大持仓和报告期 |
| 批量区间收益 | 查询预设周期或自定义区间收益 |
| 批量历史分红 | 查询历史分红记录 |
| ETF涨幅榜 | 查询根据当前市场实时涨幅排名的代表性ETF |
| ETF热搜榜 | 查询指数直通车小程序上用户搜索的热门ETF |
| 持仓股票反查ETF | 根据股票查找持有该股票的ETF |

### 场外指数基金查询能力（`open-fund-query`）

| 能力 | 说明 |
|------|------|
| 关键词搜索场外基金 | 按代码、名称、指数、主题召回场外基金候选 |
| 批量场外基金详情 | 查询规模、费率、风险等级、基金经理、关联ETF等 |
| 批量场外基金持仓 | 查询前十大持仓和报告期 |
| 批量区间收益 | 查询预设周期或自定义区间收益 |
| 批量历史分红 | 查询历史分红、到账日期和分红金额 |

## 额度说明

每位用户每日享有 **500 次免费 API 接口调用额度**（单次提问可能调用多个接口，额度按实际接口调用次数计算）。

额度耗尽后可在小程序「AI Skills」页面点击申请增加额度，每次可增加 **500 次** API 查询额度，**每日限增加一次**。

## 常见问题

**Q1：提示今日提问次数已经耗尽怎么办？**

请在小程序「AI Skills」页面点击申请增加额度，即可增加 500 次新的 API 查询额度，每天限增加一次。

**Q2：我的 Key 不小心泄露了，发现有异常的大量 Skill 调用怎么办？**

请进入小程序 AI Skill 页面 → 我的 API Key 管理 → 申请重置 API Key。重置后原有 Key 将失效，需将新的 Key 发送给智能助手，告知：

```
请修改我的指数直通车 AI 技能包（etf-fund-query、open-fund-query）的 API Key 为 XXXXX
```
