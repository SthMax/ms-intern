Description
基金久期计算方法、装置、计算机设备和可读存储介质
技术领域
本发明涉及数据处理技术领域，尤其涉及一种基金久期计算方法、装置、计算机设备和可读存储介质。
背景技术
久期是衡量债券价格对利率变动敏感度的重要指标之一，在债券型基金等资产组合的风险评估与监测中被广泛使用。现有的基金久期计算方式通常依赖基金持仓明细与债券现金流折现等计算过程，需要对组合中每一只债券的现金流进行处理并完成折现汇总。对于包含多只债券且持仓动态变化的基金组合，该类计算往往涉及大规模明细数据的频繁读取、现金流展开与多轮数值运算，计算复杂度高、耗时长。
另一方面，在仅基于基金净值时间序列进行估算的场景下，通常需要对基金净值与一个或多个债券指数的历史变化关系进行建模并据此推算基金久期。该类建模计算需要在预设历史窗口内生成基金及债券指数的增长率序列，构建回归自变量矩阵与因变量向量，并在约束条件下完成参数求解，再结合债券指数久期完成基金久期的加权计算。当待处理基金数量较大时，容易出现计算吞吐低、整体耗时过长的问题，由于计算过程中重复访问数据库，也造成数据读取与计算资源的占用，进一步降低处理效率，影响久期估算结果的及时产出。
因此，在面向大规模基金产品的久期计算时，如何提升久期估算结果的计算时效，成为本领域亟需解决的技术问题。
发明内容
本发明的目的是提供一种基金久期计算方法、装置、计算机设备和可读存储介质，用于解决现有技术中的上述技术问题。
一方面，为实现上述目的，本发明提供了一种基金久期计算方法。
该基金久期计算方法包括：获取待处理基金产品集合对应的基金净值时间序列数据，以及至少一个债券指数对应的指数价格时间序列数据和指数久期数据；初始化内存数据区，其中，内存数据区包括基金数据区、共享指数数据区、基金特征缓存区和指数特征缓存区；按基金标识分片将对应的基金净值时间序列数据加载至基金数据区；将指数价格时间序列数据和指数久期数据加载至共享指数数据区；在预设历史交易日窗口内，根据基金净值时间序列数据计算得到基金增长率序列，并按基金标识分片将对应的基金增长率序列写入基金特征缓存区；在预设历史交易日窗口内，根据指数价格时间序列数据计算得到债券指数增长率序列并写入指数特征缓存区；建立线程池与任务队列，将各基金产品对应的基金久期计算任务提交至线程池并行执行，其中，基金久期计算任务包括：读取内存数据区的数据，根据债券指数增长率序列构建自变量矩阵；根据基金增长率序列构建因变量向量；根据样本点的时间序号生成指数衰减权重向量；在回归系数向量满足非负约束及和约束的条件下，根据权重向量对自变量矩阵与因变量向量的残差项施加权重，通过对带权目标函数进行优化求解以获得回归系数向量，根据指数久期数据与回归系数向量计算基金久期；输出各基金产品对应的基金久期与回归系数向量。
进一步地，在日度更新场景下，当获取到新增交易日数据时，仅增量计算新增交易日对应的基金增长率与债券指数增长率，并更新基金特征缓存区与指数特征缓存区中对应的滑动窗口数据。
进一步地，输出各基金产品对应的基金久期与回归系数向量的步骤包括：将基金久期与回归系数向量写入数据库进行存储；在日度更新场景下，通过对带权目标函数进行优化求解以获得回归系数向量时，从数据库读取上一交易日存储的回归系数向量作为本次优化求解的初始解。
进一步地，非负约束包括回归系数向量各元素均大于或等于0；和约束包括回归系数向量各元素之和等于1；对带权目标函数进行优化求解时，对回归系数向量各元素设置取值范围为[0,1]的边界约束。
进一步地，在构建自变量矩阵与因变量向量之前，该方法还包括：将基金增长率序列与债券指数增长率序列按照交易日进行对齐；根据对齐后的共同交易日集合选取样本点，以构建自变量矩阵与因变量向量。

实施例一
本发明实施例提供了一种基金久期计算方法，通过该方法，能够在多基金并发计算场景下，提升多基金批量计算的处理效率。具体地，图1为本发明实施例一提供的基金久期计算方法的流程图，如图1所示，该实施例提供的基金久期计算方法包括如下步骤S101至S108。
步骤S101：获取待处理基金产品集合对应的基金净值时间序列数据，以及至少一个债券指数对应的指数价格时间序列数据和指数久期数据。
其中，基金净值时间序列数据包括按交易日排列的、包括交易日和基金净值的数据记录。指数价格时间序列数据包括按交易日排列的、交易日和指数价格的数据记录；指数久期数据包括与交易日关联的指数久期值，或与指数标识、交易日关联的指数久期值序列。可选地，基金产品集合可由基金标识列表表征，每一基金标识唯一对应一只基金产品。
步骤S102：初始化内存数据区。
其中，内存数据区包括基金数据区、共享指数数据区、基金特征缓存区和指数特征缓存区。
其中，共享指数数据区用于存放被多个基金久期计算任务复用的指数相关数据；基金数据区用于按基金标识分片存放各基金的净值数据；基金特征缓存区用于按基金标识分片缓存各基金的增长率序列；指数特征缓存区用于缓存债券指数增长率序列。可选地，内存数据区可实现为进程内内存结构、内存映射结构或内存缓存组件，以减少对外部存储的重复读写。
步骤S103：按基金标识分片将对应的基金净值时间序列数据加载至基金数据区。
其中，为不同基金标识维护相互隔离的数据槽位或分片容器，使得针对某一基金执行的计算任务能够定位并读取该基金分片内的数据。
步骤S104：将指数价格时间序列数据和指数久期数据加载至共享指数数据区。
其中，指数价格时间序列数据与指数久期数据可按指数标识分别存储，供后续构建自变量矩阵以及久期向量时读取。
步骤S105：在预设历史交易日窗口内，根据基金净值时间序列数据计算得到基金增长率序列，并按基金标识分片将对应的基金增长率序列写入基金特征缓存区。
其中，预设历史交易日窗口用于限定样本点范围，例如可为最近N个交易日，可选地，设置为最近35个交易日，基金增长率序列用于表征基金净值在相邻交易日之间的变化比例。可选地，当基金净值存在缺失交易日时，可仅在有效相邻交易日对上计算增长率，并将缺失交易日对应的样本点在后续对齐步骤中剔除或忽略。
步骤S106：在预设历史交易日窗口内，根据指数价格时间序列数据计算得到债券指数增长率序列并写入指数特征缓存区。
其中，当存在多个债券指数时，指数特征缓存区可存储与各指数标识关联的增长率序列。同一交易日下的不同指数增长率可用于后续构建自变量矩阵的一行样本。
步骤S107：建立线程池与任务队列，将各基金产品对应的基金久期计算任务提交至线程池并行执行。
其中，创建线程池，并发处理多个基金。每个基金独立计算，结果通过回调函数存储。基金久期计算任务包括以下子过程：
读取指数特征缓存区中的债券指数增长率序列，根据债券指数增长率序列构建自变量矩阵A。其中，自变量矩阵A的行用于表征样本点（也即交易日）序列，列用于表征债券指数维度，当存在M个债券指数且选取N个样本点时，自变量矩阵A可为N×M。
读取基金特征缓存区中该基金分片对应的基金增长率序列，根据基金增长率序列构建因变量向量b。其中，因变量向量b与自变量矩阵A在样本点维度上对应，即每一元素对应同一交易日样本点的基金增长率。
根据样本点的时间序号生成指数衰减权重向量w。其中，时间序号可按样本点从旧到新或从新到旧编号；指数衰减权重用于对不同时间样本点赋予不同权重，使得近期样本点对目标函数的贡献更大。可选地，指数衰减权重可满足随样本点越接近窗口末端交易日而权重越大。

采用该实施例提供的基金久期计算方法，提供了一种自动化基金久期算法，减少人工干预，通过将指数数据在共享指数数据区复用、将基金数据按基金标识分片并缓存增长率特征，配合线程池并行执行多基金计算任务，能够降低重复数据读取与计算开销，提升多基金批量计算的处理效率；同时，通过指数衰减权重与带约束的带权优化求解获得回归系数向量，使基金久期计算能够更侧重近期样本并保持系数的归一化与非负性，从而提高久期估算准确性、稳定性与可用性。
可选地，在一种实施例中，在日度更新场景下，当获取到新增交易日数据时，仅增量计算新增交易日对应的基金增长率与债券指数增长率，并更新基金特征缓存区与指数特征缓存区中对应的滑动窗口数据。
具体而言，每日收盘后或每日固定时间点新增一条交易日净值与指数价格数据，滑动窗口数据为预设历史交易日窗口覆盖的最近N个样本点集合。当新增交易日t的数据到达时，可仅基于交易日t与其相邻前一交易日t-1的数据计算新增的增长率样本点，并将窗口内最旧的样本点移出缓存区，实现从而保持缓存区内样本点数量与预设历史交易日窗口一致。
采用该实施例提供的基金久期计算方法，通过对新增交易日数据执行增量增长率计算并维护滑动窗口缓存，避免对窗口内全部历史数据重复计算，使得在日度滚动更新时能够进一步降低计算量与更新时间开销，从而提升久期结果的更新实时性。
可选地，在一种实施例中，输出各基金产品对应的基金久期与回归系数向量的步骤包括：将基金久期与回归系数向量写入数据库进行存储；在日度更新场景下，通过对带权目标函数进行优化求解以获得回归系数向量时，从数据库读取上一交易日存储的回归系数向量作为本次优化求解的初始解。
具体而言，以基金标识、交易日为索引字段存储基金久期与回归系数向量，在日度更新场景下，通过对带权目标函数进行优化求解以获得回归系数向量时，将上一交易日的回归系数向量作为优化算法的初始迭代点，以减少从随机初值或固定初值开始导致的迭代次数。
采用该实施例提供的基金久期计算方法，通过数据库持久化保存历史回归系数向量，并在下一交易日优化求解时进行初始解复用，使优化过程更易收敛并减少迭代计算开销，从而在连续日度更新的场景下进一步提升整体计算效率与稳定性。
可选地，在一种实施例中，非负约束包括回归系数向量各元素均大于或等于0；和约束包括回归系数向量各元素之和等于1；对带权目标函数进行优化求解时，对回归系数向量各元素设置取值范围为[0,1]的边界约束。
具体而言，非负约束与[0,1]边界约束共同限制回归系数向量各元素不取负值且不超过1；和约束使回归系数向量满足归一化条件，使其能够作为指数久期加权计算时的权重向量使用。在求解时可采用满足等式约束与边界约束的优化方式，将各元素之和等于1的条件作为等式约束项处理，将各元素属于[0,1]作为边界约束项处理。
采用该实施例提供的基金久期计算方法，通过对回归系数向量施加非负、归一化及边界约束，使回归系数向量具备可解释的组合权重含义，避免出现系数为负或系数和偏离预设和值导致的异常加权，从而提升久期计算结果的可用性与数值稳定性。
可选地，在一种实施例中，在构建自变量矩阵与因变量向量之前，该方法还包括：将基金增长率序列与债券指数增长率序列按照交易日进行对齐；并根据对齐后的共同交易日集合选取样本点，以构建自变量矩阵与因变量向量。
具体而言，以交易日作为主键，对基金增长率序列与各债券指数增长率序列进行关联匹配，仅保留双方均存在数据的交易日，得到共同交易日集合，也即对齐后得到的交易日交集。可选地，当基金因停牌、净值缺失或指数数据缺失导致某些交易日无法形成增长率样本点时，可通过对齐过程自动剔除该部分交易日，从而保证自变量矩阵与因变量向量在样本点维度一致。
采用该实施例提供的基金久期计算方法，通过对基金增长率序列与债券指数增长率序列进行交易日对齐并基于共同交易日集合构建样本点，避免因时间轴不一致引起的矩阵、向量错位，从而提升带权拟合与回归系数求解的正确性与鲁棒性，进而提升基金久期计算结果的可靠性。
