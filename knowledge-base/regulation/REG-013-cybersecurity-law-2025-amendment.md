# 中华人民共和国网络安全法（2025年修正）

[官方现行修正文本](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm) · [修改决定](https://www.cac.gov.cn/2025-10/29/c_1763461514768457.htm) · [原始HTML](../sources/REG-013/source.html) · [提取文本](../sources/REG-013/original.md) · [元数据](../sources/REG-013/metadata.json)

2025-10-28通过的修改决定自2026-01-01施行。原法末条保留2017-06-01原始施行日，不能据此忽略修正日期。本轮直接复核修正文本与修改决定；未在本轮定向检索中发现更新版本。

| 定位 | 复核结论 | 对本项目的含义 |
|---|---|---|
| 第2条 | 适用活动包括境内网络的建设、运营、维护和使用 | 内部部署不等于排除网络安全法 |
| 第20条 | 新增AI技术、基础设施、伦理、风险监测与监管的政策条文 | 不等于已批准某个LLM或给出特定模型准入清单 |
| 第23条 | 等保义务、负责人、攻击防范、日志、分类与备份加密 | 原2016文本第21条现为第23条；相关网络日志至少6个月。不能扩写成全部Prompt/原始聊天一律保存6个月 |
| 第27条 | 应急预案、风险处置及依法报告 | 纳入COD现有事件处理流程，具体责任人待内部确认 |
| 第33、39条 | 关基重点保护及特定境内数据存储/出境规则 | 金融属于列举行业，但不能仅以行业标签认定具体系统为关基 |
| 第42条 | 网络运营者个人信息保护，新增与民法典/个保法衔接 | 与REG-002一起使用，不以“服务器在境内”代替数据合规判断 |

以上为公开文本研究摘要；COD等保级别、关基认定、网络边界和日志制度仍须内部事实确认。完整核验见[本轮复核结果](review-results-2026-09-09.md)。
