# Onshore Fund Manager AI/LLM Landscape

## Inclusion rule

Include an entity in the verified set only if it is an onshore mutual fund
management company and a public primary source identifies a concrete AI/LLM
initiative, capability, partnership, procurement, product feature, or deployment.
General statements that “AI is important” remain candidates, not verified
initiatives.

## Interpretation guardrails

- Vendor involvement does not prove the fund manager uses the system in
  production.
- A named model or partner should be recorded only when explicitly disclosed.
- Never guess deployment topology from a product name.
- Peer activity demonstrates market interest, not compliance approval or ROI.
