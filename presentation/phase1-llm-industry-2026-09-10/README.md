## 源文件

- `src/build.mjs`：基于Artifact Tool的JavaScript生成脚本。
- `src/slide-manifest.json`：页目及来源对应。
- `build.sh`：使用本机Codex自带运行时重新生成。

重新生成时指定一个新的输出文件名，避免覆盖已经交付的版本：

```bash
./build.sh fund-llm-industry-r2.pptx
```

脚本从仓库中的报告来源清单、规模数据和Man原图读取材料，不调用模型、不进行新的研究或回测。构建与校验中间文件位于忽略跟踪的目录。原始报告及知识库保留原样。
